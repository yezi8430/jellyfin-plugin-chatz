Chatz 推送设置

推送目标

Chatz 与 Gotify 可以同时开启，同一条通知会分别推送到两边。

例如：http://192.168.1.10:20010（只填到域名/端口，不要带 /hook）
在 Chatz WebUI 创建「应用」后得到的应用 Token（不是全局 AUTH_TOKEN）
Chatz 频道 ID（可选）
留空或 0 = 使用该应用自己的默认频道
逗号分隔，例如：jellyfin,播放 —— 供 Chatz 路由规则匹配

Chatz 会把 5 分钟内「同应用 + 同频道 + 同标题」的消息聚合折叠成一条。 若希望每条通知都独立显示，请在下方标题模板里带上变量（如 {itemName}）。

例如：https://mess.example.com
在 Gotify 服务端创建应用后获得的 Token
用于封面图片推送，例如：https://jellyfin.example.com
开启后消息体使用 Markdown 格式，网页端和 App 内可显示内联封面图

播放进度推送

每集首次达到设定百分比时推送一次。冷却时间过后（或播放下一集）会再次推送，不会漏通知。
追剧连播时每集都会先到阈值（进度通知）再播完（停止通知），去掉后者能省掉一半噪音。 没到阈值就手动停止的，仍会照常推送。

通知类型与自定义模板

勾选启用通知。每个通知可单独设置优先级（0-10）和封面推送。标题和内容均可自定义，留空则使用默认值。

默认收起；改过标题或内容的会标记「已自定义」。展开后点变量标签可直接插入光标处。
